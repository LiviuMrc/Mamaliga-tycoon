# 🌽 Mămăligă Tycoon

Un idle clicker în care construiești un imperiu de mămăligă, de la un ceaun până la export în UE. Proiect făcut cu AI pentru live programare.

## Stack

- HTML + CSS + JavaScript vanilla (fără framework, fără build)
- `localStorage` pentru salvare automată

## Funcționalități

- Click pe ceaun → mămăligă (cu animație „+N”)
- Magazin cu 7 upgrade-uri (Făcăleț, Bunica, Brânză de oi, Fabrică de mujdei, Nuntă la Orhei, Export în UE...) cu preț care crește cu 15% la fiecare cumpărare
- Producție pasivă pe secundă
- Evenimente aleatoare (vecinul vine la gustare, hram în sat...)
- Realizări
- Salvare automată la fiecare 5 secunde, buton de reset

## Pornire

Deschide `index.html` în browser. Atât.
